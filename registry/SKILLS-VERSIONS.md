# Versiones y cambios de Skills
Registro de sección · Actualizado: 2026-11-21

## Política
Cada Skill conserva su versión **individual** dentro de `metadata.version` de su frontmatter existente. La última modificación se anota en `metadata.last_modified` (fecha ISO). No añadir changelogs extensos dentro de SKILL.md. El historial resumido se mantiene exclusivamente aquí; Git conserva el detalle. No confundir versiones de Skills con la versión global del Harness. No modificar `metadata.version` sin cambio de comportamiento o corrección real; añadir una fecha no implica publicar nueva versión de capacidad.
