## Decisiones de diseño y delta
1. Code único líder; conservar prompt/modelo/permiso nativos y esquema. No nuevos agentes, skills, hooks, servicios, ni herramientas.
2. Mantener N1–N4; objetivo hasta resultado o bloqueo material; usar referencias conocidas, búsquedas proporcionales, agrupar consultas independientes, todo nativo solo si útil.
3. Reconciliar cada evento por dueño, versión, criterio y capacidad; liberar dependencias aceptadas sin barrera de ola, conservar parcial y bloquear solo lo afectado. No polling, doble escritor o reintento sin hipótesis.
4. Mantener autoridad humana: allow no es autorización, goal/report no certifica; continuidad programada, procesos persistentes o sesiones nuevas requieren alcance autorizado. No usar cron/wakeup para suplir Task.
5. Conservar aceptación objetiva, revisión independiente y revalidación del delta material, permisos de roles, Git y modelo central sin cambios. No optimizar a costa de garantías.
