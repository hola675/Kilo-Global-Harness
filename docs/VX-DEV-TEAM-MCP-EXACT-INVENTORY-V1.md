# MCP Exact Inventory V1

Este registro distingue:

- `runtime_verified_exact`: ID exacto ya observado/certificado;
- `candidate_exact`: ID exacto derivado de source/config, todavía no observado en runtime;
- `candidate_tool_names`: nombre lógico cuya clave efectiva aún puede variar.

Solo `runtime_verified_exact` puede considerarse evidencia de identidad efectiva, y aun así no implica autorización para nuevos roles.

Actualmente la evidencia exacta certificada sigue limitada a las cinco tools documentales de Research/Architect.
