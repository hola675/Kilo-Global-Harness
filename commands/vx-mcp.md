---
description: Auditar conexión y coste contextual de servidores MCP globales
---

Inspecciona la configuración global de Kilo (`~/.config/kilo/kilo.jsonc`) sin mostrar ni copiar secretos. Enumera nombres, tipos, ejecutables o endpoints (sin parámetros sensibles) y estado cuando exista evidencia de ejecución real. Distingue servidor configurado vs conectado. Para Codebase Memory verificar proceso, índice, frescura y cobertura; para Cloudflare/GitHub credenciales no reveladas. No instalar ni mutar servidores salvo petición específica. Sugiere desactivar los no usados y fijar versiones verificadas, sin romper la configuración. $ARGUMENTS.
